# GRILLO Restaurant — React JS

A responsive restaurant website for GRILLO in Old Sidon, Lebanon, converted from HTML/CSS/vanilla JavaScript to React JS with Vite and React Router.

## Pages
- Home: restaurant introduction and photo gallery
- About: restaurant story
- Services: breakfast, lunch and contact features
- Menu: dynamic React menu with category filters and live search
- Contact: phone, Instagram, address and an email draft form (requires a configured email client; **does not submit to a server**)

## Setup
Install Node.js (LTS), then run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. For a production build run `npm run build` and preview with `npm run preview`.

## Deployment
Push this project to GitHub, then import it in Vercel. Framework: Vite; build command: `npm run build`; output directory: `dist`. `vercel.json` supports React Router direct links.

## Technologies
React, React Router, Vite, CSS, Git and GitHub.
